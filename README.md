# She Thrives Coaching — final GitHub Pages package

## Publishing
Upload the CONTENTS of this folder to the root of the GitHub repository. Do not upload the ZIP itself.

## URLs
- English: https://shethrivescoach.com/
- Serbian: https://shethrivescoach.com/sr/
- Booking: https://calendly.com/coachingshethrives

English is the default homepage. The language switcher uses real URLs; it does not use localStorage or JavaScript to remember a language.

## Required GitHub Pages settings
- Source: Deploy from a branch
- Branch: main
- Folder: /(root)

The repository should contain index.html at its root and sr/index.html for Serbian.
