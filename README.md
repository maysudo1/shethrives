# She Thrives Coaching — SEO/AEO/GEO-ready website

This package preserves the existing She Thrives visual design and adds a search-ready English/Serbian structure.

## Structure
- `index.html` — English homepage
- `sr/index.html` — Serbian homepage
- `assets/` — logo, favicon, OG image, legal-page CSS
- `privacy.html`, `terms.html`, `disclaimer.html` — starter legal pages
- `sr/privacy.html`, `sr/terms.html`, `sr/disclaimer.html` — Serbian versions
- `robots.txt`
- `sitemap.xml`

## GitHub Pages
1. Upload the contents of this folder to the repository root.
2. Ensure `index.html` is in the repository root.
3. Enable Settings → Pages → Deploy from branch → `main` → `/(root)`.
4. After your custom domain is connected, verify `https://www.shethrives.online/` and `https://www.shethrives.online/sr/`.
5. Submit `https://www.shethrives.online/sitemap.xml` in Google Search Console.

## Important
- The legal pages are starter templates, not legal advice. Review them for your actual business, jurisdiction, payment provider, analytics and booking tools before launch.
- Replace/remove any placeholder testimonial before publishing.
- Verify the actual qualifications and claims in the About section before launch.
